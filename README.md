# Ruang Literasi

Website statis untuk pembelajaran matematika materi rasio dengan konteks budaya Aceh dan pendekatan Hypothetical Learning Trajectory (HLT).

## Menjalankan website

Buka `index.html` di browser. Website ini menggunakan HTML dan CSS tanpa proses build.

## Struktur berkas

- `index.html` — konten dan struktur halaman.
- `styles.css` — tampilan dan gaya halaman.
